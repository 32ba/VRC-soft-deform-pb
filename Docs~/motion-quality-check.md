# 動作確認の手順

## 揺れを確認する

1. Setup Inspectorの**動かして確認**、または `Tools > Soft Deform PB > Motion Quality Check` を開く。
2. 対象アバターとモーションを選ぶ。任意のAnimationClipを指定できる。
3. **揺れを確認する（Play Mode）**を押し、確認用アバターの動きを見る。
4. **動きを見ながら調整**のパッドで設定を変える。
5. パッドから手を離し、更新後の動きを確認する。

Gesture Managerが導入済みの場合は、そのモーションも選べる。
Edit Modeの姿勢プレビューでは物理による揺れを確認できないため、揺れの比較にはPlay Modeを使う。

## 変更前と調整中を比べる

**A · 変更前を見る**は確認開始時の設定、**B · 調整中を見る**は現在の調整値を使う。
どちらもSoft Deform PBを導入した状態なので、未導入アバターとの比較には別の複製を用意する。
同じモーションと体型で、静止時の形、動きの大きさ、止まった後の戻り、衣装の伸びを見比べる。

**採用して終了**を押すとEdit Modeへ戻り、調整値を元のSetupへ反映する。
採用せずに終了した場合は、確認ウィンドウに残る調整値を採用するか破棄するか選ぶ。
反映後はUndoで戻せる。シーンの保存は通常どおり行う。

## 体型をそろえる

**確認中の体型・シェイプ**でサイズ用パラメーターの固定をONにし、比較する体型を選ぶ。
ほかのパラメーターは**ほかの体型・表示パラメーターを追加**から選べる。
衣装も連動するサイズ変更には、アバターのサイズ用パラメーターを使う。

メッシュごとに指定する場合は、**個別のシェイプを固定（Animatorより優先）**を開き、シェイプを**固定に追加**する。
解除するときはチェックをOFFにするか、右の×を押す。
この体型固定は確認用で、**採用して終了**では揺れの調整値だけを採用する。

## 記録と最終確認

CSVを出力すると、同じ条件での移動量や速度を見比べられる。
これらの数値だけでは、衣装の貫通や最終シルエットの良し悪しは判定できない。
Unityで調整した後は、VRChatでも接触、掴み、体型変更と他者からの表示を確認する。
